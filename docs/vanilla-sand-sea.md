# Vanilla world with a Dune Sand sea (prompt 21)

Terrain, caves, ores: vanilla, unchanged. Everything is data, generated by `node tools/rewrite/gen.js` (after `tools/rewrite/extract-vanilla.sh`):

- `worldgen/noise_settings/arrakis.json`: copy of `minecraft:overworld` with `default_fluid` = `islandcraft_dunesofarrakis:dune_sand` and the surface rule reduced to the vanilla bedrock floor and deepslate gradient (stone is the default block). `sea_level` 63 (vanilla), router entries point at `minecraft:overworld/...`.
- `worldgen/biome/arrakis_stony_peaks.json`: vanilla stony_peaks with ore features only, no spawners, desert weather and look, vanilla carvers.
- `worldgen/world_preset/arrakis.json`: overworld = noise + these settings + `minecraft:fixed` biome source.

Knobs for the next steps: `default_fluid`, `sea_level` (one number), the router entries (`continents`, `offset` spline in `minecraft:overworld/offset`), the biome's `carvers`.
Earlier terrain work (sections, pillars, noise islands, dunes) is in git history (tags noise-islands-v2, cells-v1).
